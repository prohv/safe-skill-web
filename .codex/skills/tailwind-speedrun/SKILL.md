# Tailwind Speedrun

- Build the smallest useful UI that still feels intentional.
- Prefer strong hierarchy, obvious status colors, and low-friction navigation.
- Optimize for report readability, quick marketplace scanning, and sub-second perceived load.
- Keep component count low and avoid premature abstraction.
- Use server-rendered layouts by default and add client interactivity only where necessary.
- Design around SafeSkill states like `SAFE`, `WARN`, and `BLOCKED`.
- Favor accessible spacing, contrast, and mobile-friendly stacking.
- Use `PRD.md` for screen priorities and product boundaries.
